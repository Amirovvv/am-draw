# amdraw

Идёт переписывание v1 → v2. В начале каждой сессии прочитай `.claude/CONTEXT.md` (статус) и `.claude/PLAN.md` (решения и этапы).
После каждой задачи обнови статус и журнал в `.claude/CONTEXT.md`.

- Одна сессия = один этап (или его часть) = один PR в `feat/v2`
- Перед кодом этапа покажи план этапа и дождись подтверждения
- Решения из таблицы в PLAN.md не пересматривать без явной причины
- Компоненты не импортируют supabase напрямую — только через `features/*/api/*`
- Mobile-first: любую UI-задачу проверять в эмуляции iPhone
